# ctf-writeups

A structured CTF learning path from picoCTF to Hack The Box Starting Point to TryHackMe, with a methodology writeup for every challenge. Flags are redacted, and only content the platforms allow to be published is included.

**Status:** specification. See [`specs/001-ctf-writeups/`](specs/001-ctf-writeups/).

## Local setup

```
make setup      # enable the gitleaks pre-commit hook
make gitleaks   # full-history secret scan (docker)
```
